# Earthquake Damage Prediction

## Objective
Predict earthquake damage grade:

1 = Low Damage
2 = Medium Damage
3 = Severe Damage

## Technologies
- Python
- Pandas
- Scikit-Learn
- XGBoost
- Streamlit

## Project Flow
1. Load Data
2. EDA
3. Data Cleaning
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Save Model
8. Streamlit Deployment
